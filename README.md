# terra-hackclub2
For terra hackclub

Chess, enter the names of the players at the start, and choose a time system (minutes per person | increment per move), or choose 0|0 for no time pressures, don't like the existing options? Use the custom setting to enter minutes and increments to play with whatever time you want, also enter which gamemode you want (only one for now might add more), and press enter to confirm selections. Once you are in you can play against your friend/enemy, click on pieces to see where they can move to (dot for legal move, circle for legal move that can take a piece).

---

Prerequisites

Before playing, make sure you have the **Java Development Kit (JDK 8 or higher)** installed. 

To verify if Java is installed, open your terminal or command prompt and run:
```bash
java -version
javac -version
```

---

How to Download and Setup

1. Clone the Repository
Open your terminal or command prompt and run:
```bash
git clone https://github.com
cd terra-hackclub2.git
```
*(Alternatively, click the green **Code** button on GitHub, select **Download ZIP**, and extract the contents to a folder on your computer).*

---

Running the Game

You can compile and run the game directly using the standard Java compiler. 

Step-by-Step Instructions:

1. Open your terminal or command prompt and ensure you are inside the `terra-hackclub2` root directory.
2. Compile the Java files:
   ```bash
   javac *.java
   ```
3. Launch the game:
   ```bash
   java Main
   ```

---

How to Play

* The game runs entirely inside your terminal window.
* Follow the on-screen text prompts.
* Type your inputs, choices, or commands directly into the terminal and press **Enter** to submit.
